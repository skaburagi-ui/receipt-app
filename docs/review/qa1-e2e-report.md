## 1. 見つけた不具合と修正

### BUG-1【致命・修正済】ブラウザーで PDF が作れない
- 症状：「PDFを保存」を押しても何も起きず、`Standard font "Helvetica" is not registered. Call registerStdFonts()` で失敗する。
- 原因：`pdfkit` の `package.json` `exports` は、Node では `pdfkit.node.mjs`（標準フォント登録済み）、**それ以外（Vite のブラウザー／Worker ビルド）では `pdfkit.browser.mjs`（標準フォントは `registerStdFonts()` で登録しないと使えない）** を読む。`new PDFDocument()` は既定フォント Helvetica を即座に読み込もうとするため、日本語フォントだけ登録していても失敗する。Node 上の vitest は Node 用ビルドを読むため、テストでは検出できなかった。
- 修正：`src/pdf/generate.ts` の `new PDFDocument({...})` に `font: ''` を追加（既定フォントを読み込ませない。使うのは `registerFont` した日本語フォントのみ。標準フォントを登録しないので PDF も肥大化しない）。
- 確認：修正を一時的に外すと、E2E の PDF 保存がダウンロードされず失敗することを確認（修正を戻して合格）。
- 回帰テスト：
  - `src/pdf/generate.browserbuild.test.ts`（vitest）：`vi.mock('pdfkit')` でブラウザー用ビルドに差し替え、`generatePdf` が成功することを確認。修正を外すと `Standard font "Helvetica" is not registered` で失敗することを確認済み。
  - `tests/e2e/pdf-basic.spec.ts`（実ブラウザー）。

### BUG-2【致命〜高・修正済】アプリ内で作る角印が、プレビューにも PDF にも出ない
- 症状：詳細設定→角印→「アプリで作る」で文字を入れても、「文字を入れると、ここに表示されます」のままで、プレビューも PDF も角印なし。エラー表示もなく、利用者には原因がわからない。
- 原因：`loadSealFont()`（`src/seal/seal.ts`）が**アプリのどこからも呼ばれていなかった**。`buildSealOps`／`findUnsupportedChars` が「角印用フォントが未ロード」で例外になり、`buildSheet` が例外を握りつぶして角印だけ省略していた（画像アップロードの角印は影響なし）。UI のテストは `seal/seal` をモックしており検出できなかった。
- 修正：`src/ui/hooks.ts` の `useFonts()` で、領収書フォントと一緒に `loadSealFont()` も読み込み、読み込み完了後に再描画する。`src/ui/ui.test.tsx` のモックに `loadSealFont`／`isSealFontLoaded` を追加。
- 確認：3デザイン×4形式の PDF すべてに角印が出る（目視）。「山田」「株式会社山田商店」とも表示。
- 回帰テスト：`tests/e2e/designs.spec.ts`（`.seal-preview svg` が出ること、PDFを生成できること）。

### BUG-3【中・修正済】スマホ幅で、一括発行の「宛名」入力欄が幅23pxに潰れる
- 症状：390px幅で「まとめて発行」の確認画面（手順3）の宛名欄・敬称欄が約23pxになり、入力も読み取りもできない。
- 修正：`src/styles.css`で `.recipient-table input[type="text"] { min-width: 11rem }`、`select { min-width: 6.5rem }`。表は既存の `.table-wrap`（`overflow-x:auto`）内で横スクロールする（ページ全体の横スクロールは発生しない）。
- 回帰テスト：`tests/e2e/layout.spec.ts`（宛名欄の幅 ≥120px）。

### BUG-4【低・修正済】スマホ幅で、固定の操作バーが画面最下部のフッター（ライセンス表示）の最後の行に被る
- 原因：`--bar-h: 76px` だが、「試し刷りページ」が2段目に折り返すと操作バーは約119px。
- 修正：スマホ幅のみ `body { padding-bottom: calc(var(--bar-h) + 3.5rem) }`。
- 回帰テスト：`tests/e2e/layout.spec.ts`（フッター下端 ≤ 操作バー上端）。
